# Alina Diadenko Portfolio

Editable static version of the Webflow portfolio.

## Run locally

```bash
python3 -m http.server 5173
```

Then open `http://localhost:5173`.

## Edit content

Most portfolio copy and case-study content lives in `app.js` in the `projects` array and page-render functions.

## Publish

This is a static site, so it can be deployed to Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any static host by publishing the project folder.
